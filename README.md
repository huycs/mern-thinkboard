A full-stack note-taking application built with the MERN stack. Users can create, edit, delete, and manage notes through a clean, responsive interface. The project demonstrates RESTful API development, database integration, and deployment of a production-ready full-stack application.

🚀 Live Demo

https://mern-thinkboard-6y5j.onrender.com/

✨ Features:
- Create new notes
- Edit existing notes
- Delete notes
- Responsive user interface
- RESTful API
- MongoDB data persistence
- Rate limiting using Upstash Redis
- Production deployment on Render

🛠 Tech Stack
Frontend: React
Backend: Node.js, Express.js, MongoDB Atlas, Upstash Redis (Rate Limiting)
Deployment: Render
